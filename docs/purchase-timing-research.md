# 购买时机 Agent · 方法论研究文档（金融学 x 量化）

> 项目代号：Iris（鸢尾花）。用途：黑客松立项依据 + 开发基线。整理日期：2026-09-04
> 一句话定位：把「现在买合适吗」从拍脑袋，变成有理论、有数据、有概率、能回测、敢解释的量化决策引擎。

## 0. 先把问题定义对：我们不是价格预测器

用户贴一个链接问「现在买合适吗」。如果只做「预测下周涨还是跌」，必输——单品价格受库存、活动、竞品、情绪影响，本质难预测。
我们做的是决策：把「买 / 等 / 换」当成不确定性下的选择问题——
- 立即买 = 拿到使用价值，但放弃未来可能更低的价；
- 等 = 保留「以后按更低价买」的可能性，但要付等待期的使用损失和「涨回去 / 断货」的风险；
- 换 = 换成性价比更高的标的（同款不同渠道、同品类不同品牌 / 档位、上下位替代）。

这个结构在金融数学里叫「最优停止 + 实物期权」（等待的权利 = 期权）。我们要做的是把成熟框架搬到消费场景，而不是发明玄学指标。

## 1. 理论地基：凭什么「概率 + 触发条件」是严谨的

### 1.1 等待期权（Optimal Stopping / Real Option）
耐用品购买的最优停止模型（Melnikov 系列模型；另有一篇 Wisconsin 产业组织博士论文专门建模「消费者只盯一款电视的价格、求解何时下手的最优停时」）给出统一结论：最优策略不是预测价格，而是设定触发边界——价格进入边界内就买，否则继续等。
- 对产品的意义：核心输出不是「会跌 20%」，而是「当前价位在历史上什么位置 + 触发条件（低于 XX 分位 / 等到某事件）」。

### 1.2 (S,s) 规则：为什么触发带要随不确定性变宽
Caballero（1993，JPE 101(2)《Durable Goods: An Explanation for Their Slow Adjustment》）证明耐用品消费对价格反应是「钝化」的——存在调整阈值带，带内不动、越过阈值才动。后续增广 (S,s) 模型进一步显示：不确定性升高时，理性消费者会加宽触发带、继续观望。
- 对产品的意义：市场越乱（矿潮、新架构传闻、关税传言），越不该催用户出手；高波动应自动调高「等」的倾向——这是有微观理论支撑的，不是保守主义。

### 1.3 通胀预期影响购买时机（宏观依据）
Coibion、Gorodnichenko、Georgarakos、Kenny（IZA DP 17317，2024，欧洲家庭调查）发现：预期通胀水平上升 → 家庭提前买耐用品；预期通胀不确定性上升 → 家庭推迟数月再买。
- 对产品的意义：问卷要问「你觉得未来半年这类东西会涨还是跌 / 涨价新闻多不多」，把宏观预期接进等待收益的估计。用户案例里「通货膨胀要不要考虑」在这里有正式答案：要考虑，但要区分「水平」与「不确定性」——两者方向相反。

### 1.4 参考价：人怎么感知贵贱
Rajendran & Tellis（1994，Journal of Marketing 58(1)《Contextual and Temporal Components of Reference Price》）：消费者判断贵不贵用的是「参考价」，由两部分组成：
- 语境参考：同品类、同渠道、替代品的价格（横向）；
- 时间参考：这个商品自己的历史价格（纵向）。
- 对产品的意义：界面必须同时给横纵两个锚——「现价 vs 历史分位（时间锚）」「现价 vs 同级替代品 / 其他渠道（语境锚）」。缺一个，用户的贵贱感知就会被锚定效应带偏。

### 1.5 行为金融：人为什么总买在高点
- 现值偏误（O'Donoghue & Rabin, 1999, AER 89(1)《Doing It Now or Later》）：人天生高估「现在拥有」、低估未来，可选品总想「早买早享受」，等不到促销窗口。
- 稀缺焦虑：倒计时、限量、涨价横幅激活损失厌恶（怕失去 500 比省下 500 更痛）。
- 对产品的意义：解释引擎负责「冷静换算」——把「等」翻译成「为省约 500 元只需等到 11 月，过去 3 年这个位置都这么走」；把「早买」翻译成「你为提前 3 个月使用，多付约 800 元溢价」。不煽动、不制造焦虑，延续旧项目「给依据、不吓人」的红线。

### 1.6 必需品与可选品：第一道闸门
必需品（药、御寒品）需求弹性低：效用损失曲线陡，等待期权价值趋近 0 → 直接建议买，只做渠道比价；可选品（显卡、游戏机）弹性高 → 走完整时机引擎。品类闸门放在问答最前，避免把简单问题复杂化。
## 2. 量化方法层：能算、能验、能解释

### 2.1 价格序列与 K 线
- 数据粒度：以「商品实体（型号 / SKU）x 渠道」为最小单元聚合日价；缺失日期不插值伪造，如实标缺失。
- K 线：日线 / 周线 OHLC（渠道间价差构成振幅），这是用户点名的输出，做。滚动分位：现价在近 90 / 365 / 730 天里的分位（时间参考价）；均线 MA20 / MA60 给趋势；区间统计用 min-max 与 IQR，而不是只报「跌了多少」。
- 波动率：滚动窗口历史波动率，进阶可加 EWMA 或 GARCH(1,1)，输出「当前波动率分位」。高波动 → 触发带自动变宽（见 1.2），即系统倾向让用户等。

### 2.2 降价概率：核心数字，必须校准
输出两种可辩护的概率（用户要求概率化表达）：
- P1 = 未来 60 天（默认，可配 30 / 90）出现「比现价低至少 5%（阈值可配）」的概率：用历史模拟——取出过去 3~5 年所有「与当前同分位段 + 同事件相位」的窗口，统计其后 60 天实际降价频率；样本不足（少于 30 个窗口）不给单点概率，只给方向 + 区间。
- P2 = 「现在买」在视野期内期望净收益为正的概率：把 P1 x 期望节省、等待使用损失、涨价 / 断货风险放进取舍（见 2.5）。
- 校准义务（工程师红线）：对外输出的概率要过校准检查——Brier Score / 可靠性图（预测 70% 的事件应约 70% 兑现）。回看样本不足一律降级为「样本不足」标签，宁缺毋滥。这是「严谨」的可验证定义；评委问「概率凭什么可信」，答校准流程。

### 2.3 事件研究：把「新品 / 大促 / 政策」变成可算的项
- 事件日历：大促（618 / 双11 / 黑五）、厂商换代（官方路线图 + 历史换代间隔推测）、政策（关税 / 税改生效日，如 2026 年显卡相关进口税调整新闻）。
- 事件窗口分析：对每类事件取历史同类事件前后 60 天价格平均路径（例：「前代同定位产品在换代前 3 个月的平均降价曲线」），得到条件期望降价曲线。
- 输出形态（复刻用户示例）：「价格处近两年 85% 分位；距下一代预计还有 8 个月；历史上到这个位置后，3 个月内降价概率约 70%」。每一句都能点开看原始统计，不允许不可追溯的数字。

### 2.4 替代品矩阵与品牌档位（语境锚的实现）
- 图谱：同型号多品牌 / 多渠道；上下位替代（5080 疯涨而 5070 平缓 → 降档建议）；品牌分低 / 中 / 高三档。
- 档位价差必须拆因：可量化部分（用料、散热规模、性能、保修年限、渠道补贴）与叙事溢价（品牌故事、生态），叙事部分明确标注「主观溢价，值不值由你定」，agent 不替用户做价值判断。
- 每个候选标的跑同一套时序统计 → 输出「对比表 + 各自 K 线」。替代建议必须带数据差（贵 15%、性能差 5%），不是感觉。

### 2.5 决策聚合：可解释的期望价值，不用玄学权重
- B = 必要性（由问答推断：用途 / 最晚期限 / 预算弹性 / 二手接受度）
- U = 等待期效用损失 = B x 等待时长 x 使用强度
- G = 等待期望收益 = P1 x 期望节省额（经事件日历调整）
- R = 等待风险 = 断货 / 停产 / 涨价反弹概率 x 对应损失
- 规则：若 G - U 大于 R + 风险厌恶缓冲 → 建议等；否则建议买；若存在替代品 j 使总成本显著更优 → 建议换。
- 透明度：每个参数挂「数据口径 + 样本量 + 假设」，界面可展开；建议用条件句给：「若你最晚 9 月底要用，建议买；若能等到 11 月，历史上 70% 概率省 8~12%」。
- 红绿灯：绿（买）/ 黄（等或换）/ 红（别现在买）由期望值差自动映射，不人工拍脑袋。

### 2.6 回测与披露纪律
- 回测：截断历史滚动前推（如用 2023-01 前数据跑规则，看之后建议的命中分布：省的比例、平均节省额、最坏情形），报告随建议可查。
- 红线：回测通过不等于未来保证；新品没有自身历史 → 用同品类生命周期代理（前代同定位曲线）并打「代理数据」标签；样本小于 30 的结论标「低置信」；绝不承诺省钱。旧项目「反诈红线」延续为「防忽悠红线」：永远给依据、给区间、给条件，不给焦虑和包票。
## 3. 数据层：先能用，再全自动
- 数据源分级：
  A 半自动（demo 主力）：用户回填（自己买过的实付价、截图价）、低频人工巡检、渠道公开价格页。
  B 比价 / 历史价工具：慢慢买（京东 / 天猫历史价，反爬严格、常需登录与验证码）、什么值得买；海外结构较好的 Keepa / CamelCamelCamel（亚马逊系）、PCPartPicker / Geizhals（硬件价格历史曲线）。
  C 行情与资讯：厂商与媒体（新品发布与定价报道）、税率 / 关税新闻、二手市场指数（闲鱼价作为真实成交价代理）。
- 现实策略：离线价格库为主（历史 bundle 随项目分发），在线刷新是渐进目标；链接解析失败 → 手动确认「商品名 + 品类」；爬虫低频、守 robots，能人工导入就不硬爬。每条价格都带来源、抓取时间、新鲜度、缺失率标签。
- 工程风险提示：中文电商反爬与验证码是最大不确定性。demo 演示路径必须走「半自动 + 预置数据」，现场不赌实时抓取。

## 4. 相比小红书攻略与比价 App，严谨在哪（答辩口径）
- 攻略贴：给结论不给依据，样本等于个人经验。我们：每个结论挂可展开的数据口径与样本量。
- 比价 App：只答「哪里便宜」，不答「何时买」。我们：时序统计 + 事件日历 + 概率与触发条件。
- 预测迷信：假装能预测涨跌。我们：给校准过的条件概率、触发边界与假设清单，样本不足就明说。
- 一句话：把机构级研究框架（分位、波动率、事件研究、期望值决策、回测、概率校准）降维到个人消费，全程可解释、可证伪。
