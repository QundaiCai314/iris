## 1. 一页纸（3 分钟讲稿 / 视频开场白）

评委好，这是 Iris——面向高单价耐用品购买，把价格变化、最晚使用期限和等待成本放进同一个可解释决策框架的量化决策 Agent。

- **核心场景与痛点**：高单价商品何时买，不仅取决于行情，更取决于消费者什么时候需要它。同一件商品，用户可以等两个月与明天必须投入工作，决策理应不同；
- **双层架构与分工**：大语言模型仅在最外层辅助解析非结构化商品描述与需求澄清；本地量化内核（纯 Python 标准库，零第三方数值计算依赖）负责严格的确定性计算，用户可即时调整假设并毫秒级重算；
- **决策输出与可解释性**：输出明确的买/等/换裁决与大白话；并列呈现客观降价概率 P1 与个人期望最优概率 P2，给出动态 $(S,s)$ 触发条件句、启发式目标击穿价（Target Strike Price）与 30 天价保预期退差估值参考；
- **计量与行为解释工具**：引入 AR(1) OLS 均值回归偏离半衰期（提供时间衰减尺度）、命中降价窗口持续时间统计，以及累积前景理论（CPT）量化测算损失厌恶心理阻力，帮助用户理解主观焦虑与偏好；
- **验证与防御性工程**：全量 123 项自动化单元测试覆盖防前视、样本不足降级与极端容错；213 个时间截断决策点对照回测验证选择性等待特征；数据全程标明合成剧本（synthetic-demo），绝无不可复现的黑盒。

## 4. 差异化口径（答辩口径，总纲 §4 + spec §4）

- 何时买 vs 哪里买：比价 App / 慢慢买类只答「哪里便宜」；Iris 答「现在买 vs 等 vs 换」的时机决策，输出概率、红绿灯与触发条件。
- 决策含使用价值：等待不是免费的——期限、使用强度、享乐系数进入期望值（U 项），纯价格预测器没有「人」这一项。
- 可校准、可回测：每个概率过 Wilson 区间与校准流程；M7.1 截断回测 213 决策点样本外验证，偏差如实披露，不做「未来保证」。
- 可解释、可证伪：条件句与分解表全部带 ref 与 n，假设 A1-A7 展示可调；样本不足（n<30）只给区间与方向。
- 反焦虑、不裁决价值：无倒计时/限量话术（全库扫描 0 违规）；品牌叙事等主观溢价单列，「值不值由你判断」。

## 5. 与大赛方向的映射

- 方向一（金融 AI 智能体）：澄清问卷 Agent（链接/文本语义解析 -> 自动生成个性化问题 -> 画像），决策工作流全自动，问答即交互入口；LLM 网关（D2，多模型路由 + 降级）设计就绪，规则化兜底已闭环。
- 方向二（量化投资策略与金融科技工具）：机构量化框架降维——历史分位、波动率、事件研究（对照组差分）、期望值决策、(S,s) 触发带、概率校准（Brier/可靠性）、截断回测；P1/P2 双概率口径用户拍板（60 天主窗）。
- 方向三（行业场景落地）：面向个人消费者的轻量化本地工具（Python + FastAPI，离线可跑，无外部依赖），先自用做真再参赛。

## 7. 评审 Q&A 预演

Q1 数据真实吗？价格哪来的？
- demo 全链为合成剧本（source=synthetic-demo，含真实量级锚点），口径与标签透明；真实历史价抓取按 B01 渐进（慢慢买等公开工具），工程风险已在 spec §6 记录。
Q2 概率凭什么可信？
- P1 = 同分位段历史窗口频率，附 Wilson 95% CI 与 n；有校准流程（Brier/可靠性）与 M7.1 样本外回测；样本 <30 自动降级为方向 + 区间。
Q3 你们和比价插件 / 小红书攻略有什么区别？
- 插件答「哪里买」，攻略给结论不给依据；我们答「何时买 + 等不等 + 换不换」，且每个数字可展开样本、口径与假设（spec §4 / 本文 §4）。
Q4 为什么这算「金融 AI / 量化」项目？
- 底层是金融数学（最优停止/期权、(S,s)、事件研究、期望值决策、概率校准、回测）的工程化；上层是 Agent 交互与决策工作流；不做荐股理财，是把机构框架降维到高频生活决策。
Q5 P2 里的主观参数（A1-A7）是不是拍脑袋？
- 方向有研究出处（R05 等），数值标注「待 B05 标定」，卡面可调、依据链可展开；回测固定参数不搜索，避免过拟合（D5）。
Q6 回测结果怎么解读？
- 回测在合成剧本内验证引擎自洽与信号质量（等建议净省 +5.82%、命中 53.3%）；样本外校准偏差已披露并挂研究信号（P1 v2 事件相位）；报告含免责声明，不承诺真实市场表现。
Q7 新品没有历史价格怎么办？
- 生命周期代理曲线族已建（data/lifecycle/），引擎接入与「代理数据」标签测试列入后续（红线清单 C2 豁免项）；当前 demo 无新品场景。
Q8 未来怎么商业化 / 继续做？
- 先自用做真：真实数据源（B01）、校准实验（B05）、品类图谱（B03）；产品形态保持本地优先、隐私友好，可横向扩到手机/家电/游戏机等品类。
