# Iris 产品规格基线 v0.1（2026-09-04）

## 1. 定位
个人消费「购买时机」量化 Agent。不做记账省钱、不做荐股理财；把机构级量化研究框架（分位、波动率、事件研究、期望值决策、回测、概率校准）降维到个人消费决策。

## 2. 用户流程
1. 用户粘贴商品链接 → 能解析则自动提取「商品名 + 品类 + 当前价」；解析失败 → 手动确认「商品名 + 品类」后继续。
2. Agent 根据商品与链接内容自动生成澄清问卷：大量选择题 + 部分填空题。
3. 得到需求画像后做全网价格调研与分析。
4. 输出决策卡（见第 4 节），可追问、可展开依据。

## 3. 澄清问卷维度（必需与可选品分流）
- 用途与使用强度（决定效用损失曲线）
- 最晚需要期限（决定可等待时长上限）
- 预算与预算弹性
- 是否接受二手 / 平替
- 必需 or 可选（药等必需品 → 跳过时机模型，只做渠道比价）
- 通胀与缺货预期（涨价新闻感知：水平 vs 不确定性，方向相反）
- 风险偏好（愿意等多久换取多少折扣）

## 4. 输出决策卡
- 结论优先（M7.5/M9）：首屏只放 红绿灯结论 + 一句大白话（plain_language，含期限与概率口径、无承诺词）+ 行为提示（M10）+ K 线与价格分位；其余金融细节（P1/P2 详解、期望值分解、事件日历、替代矩阵、假设重算、依据链）按 Tab 分栏与依据链面板展示。
- 双概率并列：P1 = 未来 60 天降价 >=5% 的概率（默认窗口 60 天，30 / 180 天辅助）；P2 = 「现在买」是 60 天视野内最优决策的概率（含使用价值与等待成本）。
- K 线 + 现价历史分位（90 / 365 / 730 天）+ 波动率分位。
- 事件日历：换代 / 大促 / 政策窗口条件期望。
- 替代品矩阵：上下位替代；同型号不同品牌低 / 中 / 高挡位 + 价差归因（用料 / 散热 / 售后 / 渠道补贴为可量化项；品牌叙事标注为主观溢价）。
- 红绿灯 + 触发条件句：「若 9 月底前要用 → 买；若能等到 11 月 → 历史 70% 概率省 8~12%」。
- 依据展开：每个数字挂数据口径、样本量、假设、代理标签。

## 5. 决策规则（可解释期望值）
买 / 等 / 换 = 比较等待期望收益 G、等待期效用损失 U、等待风险 R 后的期望值差；阈值随波动率（不确定性）自动变宽。所有参数来源透明。
- 行为提示层（M10）：输出端检测用户侧非理性噪音（大促氛围 / 高分位反弹 / 反复重算 / 刚答完冲动），命中时决策卡附琥珀色降温提示；规则确定性、不改 G/U/R/buffer/P2 数学模型、文案过禁用词红线。

## 6. 数据策略
离线价格库为主 + 半自动刷新（用户回填 / 人工巡检 / 公开历史价工具：慢慢买、Keepa、PCPartPicker 等）；每条价格带来源与新鲜度标签；中文电商反爬是最大工程风险，demo 不赌实时抓取。

## 7. 账号与数据（M8，单机 demo）
- 登录：用户名 + 密码注册 / 登录 / 登出；密码 PBKDF2-SHA256（20 万轮 + 随机盐）哈希存储，不落明文；令牌存浏览器 localStorage（7 天过期，服务重启失效）。
- 决策历史：登录用户每次出卡自动保存完整卡片快照（kind=card / no_data），列表可按时间回看、一键还原查看当时完整决策卡、重跑流程或删除；游客出卡后可补登录再存入历史。
- 画像预填：同品类问卷答案按品类存档，再次出卡自动预填，可一键沿用或逐题修改。
- 关注清单：卡片上「关注该商品 / 取消关注」，在「我的数据 → 关注商品」集中查看现价并重新出卡。
- 导出 / 注销：JSON 导出（含全部快照、关注、画像）；注销即删本机账号数据；存储为 data/users/ 单机 JSON（原子写盘），产品化时换数据库即可。

## 8. 红线
概率经校准（Brier / 可靠性图）；样本 <30 不给单点概率；新品用前代生命周期曲线并打「代理数据」标签；回测不承诺未来；不制造焦虑、不替用户做价值判断（主观溢价单列）。
