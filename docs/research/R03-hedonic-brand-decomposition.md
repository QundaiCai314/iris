# R03 特征价格模型：品牌挡位价差的严谨归因

- 编号 / 日期：R03 / 2026-09-04
- 状态：定稿（2026-09-06，已被引擎参数引用）
- 研究问题：同型号不同品牌 SKU 的低 / 中 / 高挡位价差，如何拆成「配置差异」「品牌溢价」「噪声」三部分？
- 一句话结论：用 hedonic（特征价格）回归 ln(价格) = 属性项 + 品牌哑变量，品牌系数即「控制配置后的品牌溢价」；数据不足时退化为「属性近似配对比较」。让挡位与溢价可复算，而不是让 agent 拍脑袋分挡。

## 1. 理论依据与官方实践
- Rosen（1974，JPE 82(1)，Hedonic Prices and Implicit Markets）：商品可视为特征向量的组合，市场回归给出每个属性的隐含价格——品牌溢价因此可操作化：控制所有可测属性后残留下来的价格差。
- 官方统计机构用 hedonic 指数给 IT 产品做质量调整：Triplett（2004）Handbook on Hedonic Indexes and Quality Adjustments in Price Indexes（OECD）——电脑 / 笔记本是典型应用对象。
- 显卡实证先例：Zakharov（2018，俄文期刊存档）用 hedonic 方法估计显存容量、GPU 厂商等 4 项特征对显卡价格的影响。
→ 对 Iris 的意义：显卡等硬件的 SKU 属性（性能基准、显存、散热规模、供电、保修、尺寸）都有公开可填的数据源，hedonic 路线可行。

## 2. 模型设定（Iris 版）
同一「核心型号 x 渠道类型」的样本内：
ln(P_i) = b1 x 性能分_i + b2 x 显存_i + b3 x 散热规模_i + b4 x 保修年_i + Σ g_b x 品牌_b + e_i
- 性能分用公开基准归一（3DMark / 游戏帧率 / TFLOPS 任选其一全样本统一），不用「档次」这类主观标签；
- g_b（品牌哑变量）= 剔除配置差后的品牌溢价 → 界面输出：「同配置比，该品牌贵约 ¥xxx（含售后 / 生态等不可测项），值不值由你判断」；
- e 的分布给出「同配置跨渠道价差噪声区间」，避免把渠道促销差误读为品牌差。
小样本降级：不跑回归，做属性近邻配对（同一核心型号下找属性向量最接近的跨品牌 SKU 直接比价，多对取中位数）；必须同一天、同渠道类型比较，防促销错位。

## 3. Iris 落地（代码引用 R03 §2）
- 低 / 中 / 高档位不再人工定义：按「属性向量」做简单聚类或按性能分位切挡；
- 每档输出：配置清单、价差构成（属性差多少钱 + 品牌溢价多少钱 + 噪声区间）、一句话「贵在哪里」；
- 上下位替代同理：跨型号比较时先用性能分对齐（如 5080 vs 5070：每元性能与绝对价差同时展示），避免「丐版比旗舰」。

## 4. 局限与可证伪条件
- 品牌溢价随促销周期与新品节奏漂移 → 需要滚动重估（每月或事件后）；
- 旗舰 SKU 样本少，回归不稳定 → 走配对降级路线；
- 售后体验、生态这类不可观测项残留在 g_b 中 → 界面措辞固定为「溢价成分含品牌 / 售后 / 生态，价值判断交给用户」（总纲红线：不替用户做价值裁决）。
- 可证伪：若同一品牌内部同配置 SKU 价差大于跨品牌中位差，说明渠道噪声主导，此时不出溢价结论。
