# R01 事件研究法移植：换代与大促的价格窗口

- 编号 / 日期：R01 / 2026-09-04
- 状态：草案（待评审）
- 研究问题：怎样严谨估计「新品发布后旧款 / 同款价格怎么走」「大促窗口价格怎么走」，而不是拍脑袋给降价曲线？
- 一句话结论：把金融事件研究（估计窗 - 事件窗 - 异常收益 - 累积 CAR）搬到商品价格，参照系从「市场组合」换成「同品类未受事件的对照组」；多起同类事件取平均异常路径并给样本量与置信带。

## 1. 方法与证据（金融学怎么做）
标准流程（中文权威教材：沈中華、李建然，2000，《事件研究法——財務與會計實證研究必備》，台北：華泰文化）：
1. 定义事件与事件日；
2. 划估计窗（事件前，拟合「正常水平」）与事件窗（观察反应）；
3. 正常收益模型：市场模型或常数均值模型；
4. 异常收益 AR = 实际 - 正常；
5. 累积 CAR = ΣAR，跨事件平均为 AAR / CAAR，检验是否显著异于 0。
典型应用例：iPad 新品宣告对台湾电子供应链股价的影响（李浩旭，2011，國立交通大學財務金融研究所碩士論文；市场模型 + GARCH 估计异常收益）。

## 2. 移植到商品价格的关键改动
单品价格没有「大盘收益」。替代设计（等价于双重差分事件研究）：
- 对照组 = 同品类、同生命周期阶段、未发生该事件的商品价格指数（例：显卡类目剔除事件型号后的中位价）；
- 异常降价 AR_t = ΔlnP(事件品)_t - ΔlnP(对照组)_t；
- 多起同类事件（多次换代、多年同档大促）pooling，输出平均异常路径与置信带。
如此，事件对品类的净效应可与共同冲击（矿潮、通胀、汇率）分离。

## 3. Iris 落地（代码引用 R01 §3）
- 事件字典：换代（发布会日与发售日分开记）、大促（预售开始日 / 正日子）、政策（税率生效日）、供需事件（短缺 / 砍单新闻日）。
- 估计窗：事件前 120 天；事件窗：-30 ~ +90 天（前 30 天捕捉预期与「先涨后降」）。
- 输出形态：「历史同类事件后 60 天，相对对照组平均累计降价 X%，95% 带 [a, b]，样本 n 起」——这是 P1 的日历修正项与换代降价曲线的来源。
- 清洗规则：事件日必须公开可查（发布 / 发售 / 公告）；剔除与其他大事件混叠的窗口；事后才公开的信息一律不可进估计（防前视偏差）。

## 4. 局限与可证伪条件
- 单品事件样本少（显卡换代约 2~3 年一次，n 个位数）→ 只给区间不给点概率（总纲 2.6 样本纪律）。
- 对照组假设「同期无共同事件」；促销期标价操纵（先涨后降）会使窗口路径失真 → 优先到手价 / 成交价口径（backlog B02）。
- 可证伪：若对照组路径与事件组在估计窗已显著背离（趋势不平行），该起事件剔除。
