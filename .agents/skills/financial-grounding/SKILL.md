# 金融抗幻觉与宏观政策事实核查技能规范 (Financial Grounding & Macro Policy)

在严肃金融与耐用品量化决策中，模型胡乱捏造价格预测、乱扣高大上理论帽子（如无覆盖保证却妄称共形预测、无删失统计妄称完全生存分析）、承诺虚假回报，属于一票否决级硬伤。
同时，**面向中国市场的量化 Agent 必须具备高度的宏观政策敏锐度**：中国消费品市场的价格波动深度受到中央经济工作会议、国家产业政策、财政补贴（如“两新”以旧换新、超长期特别国债）的政策周期牵引。

本技能确立金融事实核查准则、三级置信度标注体系、四条红线拦截规则，以及中国宏观政策学习与市场预判框架。

---

## 第一部分：事实核查流水线 (Fact-Checking Pipeline)

任何向用户呈现的价格、涨跌幅、概率或量化指标，必须通过三重交叉核验流水线：

```mermaid
flowchart LR
    OutputCandidate["待输出金融/价格陈述"] --> Check1["步骤 1: 真实数据源核验 (截断历史/无前视)"]
    Check1 --> Check2["步骤 2: 理论映射核验 (代码与公式完全对应)"]
    Check2 --> Check3["步骤 3: 政策逻辑核验 (中国宏观导向与补贴细则)"]
    Check3 --> AnnotateTier["附加三级置信度显式标签"]
    AnnotateTier --> FinalOutput["合规安全输出"]
```

1. **真实数据源核验 (Data Grounding)**：
   - 价格数据必须来自已登记的电商归档（如 `data/real/`）或明确标注的基准剧本；
   - 严禁杜撰未追踪商品的“历史最低价”、“平均回撤幅度”。库外商品必须坦诚披露：“当前本地无该型号价格时间序列，无法出具客观统计”。
2. **时间截断无前视核验 (Lookahead-Free Audit)**：
   - 所有回测、均线、波动率与分位，严格限定在 `asof` 截断日之前计算，杜绝用“事后最低价”假充“事前可执行买入点”。
3. **理论与代码严格一致性核验 (Implementation Correspondence)**：
   - 严禁名不副实：例如未进行动态规划反解，不可称作“SAS 最优停止反解”；未处理右删失数据，不可笼统宣称“Kaplan-Meier 完全生存分析”。

## 第二部分：三级置信度标注系统 (Three-Tier Confidence Annotation)

Agent 在阐述任何数据、结论或预判时，必须在文本中显式带有三级置信度标签：

| 置信层级 | 定义与适用范围 | 标注格式示例 | 输出要求与边界 |
| :--- | :--- | :--- | :--- |
| **Tier-1 确定性事实** | 已发生、可独立复核的客观历史数据与现货价格 | `[事实·可核验]` 或 `[数据归档]` | 附带采集渠道、时间戳（`asof`）与基准源。 |
| **Tier-2 条件量化估计** | 基于统计学与计量经济学模型（分位统计、OU 回归、CPT 效用）产出的点估计 | `[量化估计·CI 95%·n=XX]` | 必须附带样本量 $n$ 与置信区间；$n < 30$ 时强制标注为 `[低置信参考]`。 |
| **Tier-3 外部假定与政策预判** | 基于用户个人效用参数、通胀预期、中国宏观政策导向给出的情景预判 | `[参数假定·用户可调]` 或 `[宏观政策研判]` | 必须说明前提假设：“在超长期国债补贴持续落地的假设下…”并支持用户重算。 |

## 第三部分：四条幻觉拦截红线规则 (Four Interception Rules)

以下四条规则为系统最高优先级安全红线，违反任何一条均触发拦截与重写：

### 规则 1：绝对承诺与包票词零容忍 (Zero Absolute Guarantees)
- **红线禁用词**：`必涨`、`必跌`、`稳赚`、`保本`、`绝对`、`100%会`、`零风险`、`包票`。
- **违规即拦截**：金融与消费市场充满随机性与外生冲击，必须使用概率化语言（如“在历史同分位窗口下降价概率为 $P_1$”、“模型预期回归时间尺度约为…”）。

### 规则 2：无据点位与虚假收益零捏造 (Zero Fabricated Metrics)
- 当用户询问冷门或库外商品时，严禁编造“这款手机一般在发售后第 45 天降价 8%”。
- 遇到无数据情形，必须主动降级：“暂无该 SKU 的全生命周期价格轨迹，建议参考同品类宏观生命周期规律或自选导入 CSV”。

### 3. 规则 3：学术理论标签与底层实现严格对齐 (Strict Theoretical Grounding)
- **波动率经验带**：不具备在线共形分数校准保证，严禁宣称“理论覆盖保证”，规范命名为“波动率驱动的经验价格带”。
- **持续期统计**：仅对已降价窗口统计时间，规范命名为“已命中降价窗口的持续时间统计”。
- **均值回归模型**：当 AR(1) 回归系数 $\beta \ge 0$ 时，必须明示“数据呈现随机游走或单边趋势，不具备均值回归特征”，禁止输出虚假半衰期。

### 4. 规则 4：小样本与重叠时间序列强制降级 (Sample Sufficiency Downgrade)
- 历史候选窗口样本数 $n < 30$ 或时间跨度小于 90 天时：
  - 严禁出具“红色确定性等待信号”；
  - 信号灯强制降级为黄色（仅供低置信参考）；
  - 并在界面或文案中主动披露样本局限，避免给用户造成过度确信的幻觉。

## 第四部分：中国市场重要会议精神学习与宏观预判机制

面向中国高单价耐用品消费市场（数码家电、汽车、智能硬件），Agent 必须深入结合**党中央重要会议精神与国务院促消费政策部署**，给出高维度的宏观市场预判：

### 1. 核心政策底座学习框架
Agent 应系统研读并锚定以下三层政策信号：
- **顶层战略指引**（中央经济工作会议 / 中共中央政治局季度会议）：
  - 牢牢把握“**稳中求进、以进促稳、先立后破**”总基调；
  - 把握“**大力提振有效需求、激发有潜能的消费、扩大内需战略**”的核心主线；
  - 紧跟宏观逆周期调节与流动性支持节奏。
- **产业专项行动方案**（国务院《推动大规模设备更新和消费品以旧换新行动方案》）：
  - 关注超长期特别国债支持消费品“两新”的资金下达节奏（中央资金 3000 亿元左右分批下达）；
  - 关注重点支持品类：**高能效家电（8大类一级能效补贴 20%）、智能数码（手机/电脑/平板）、新能源智能汽车**。
- **部委与地方传导机制**（国家发改委、商务部、各省市促消费专班）：
  - 追踪地方以旧换新“立减 15%~20%”平台补贴（京东、天猫、线下云闪付）的活动档期与限额申领动态。

### 2. 政策向市场价格预判的传导转化矩阵

Agent 需将宏观政策语言转化为微观消费时机预判：

```text
[政策信号] 中央政治局会议部署提振消费 + 发改委统筹安排超长期国债支持资金
   ↓
[财政传导] 各省市出台以旧换新细则，主要电商平台上线“国补 15%~20% 立减”专区
   ↓
[市场现象] 耐用品发生“政策性跳空低开”，非单纯市场自发价格战，而是财政真金白银补贴
   ↓
[Agent预判准则] 
1. 若用户意向商品处于“国补”覆盖范围（如能效一级笔电、家电）：
   → 明确提示：“当前正处国家超长期特别国债以旧换新政策红利期，叠加平台大促可实现跨周期历史低点，政策窗口期价值高于单纯等待市场自然降价。”
2. 若处于政策年底额度收官或退坡窗口：
   → 提示额度用尽风险，建议在政策有效期内核销享受确定性让利。
3. 若商品属于非补贴范畴的高溢价轻奢耐用品：
   → 提示消费分层与理性购买：“当前政策重点向绿色智能和大众消费品倾斜，该款享乐品缺乏政策直接贴息，需警惕后续市场流动性溢价回撤。”
```
